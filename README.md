## About

**THE SPACE BETWEEN US.**

An open working method for one person and several voices (people, AI tools, documents) working from the same source.

Born on the night of 23.10.2026, 03:12–05:26, in Bunker 26.

### 👁️ The Work Rule

**👁️ See → 📍 Locate → 🔬 Check → Separate fact from interpretation → only then speak**

Assume nothing about the workspace. Start only from what is actually accessible.

### 🪨 Entry Card

| Field | What to write |
|---|---|
| Who did it? | Who performed the event, not who documents it |
| Recorded by | Who wrote the card |
| From where? 📍 | What was in front of the writer: which screenshot, text or source |
| When did it happen? 🕒 | |
| When was it reported? 🕒 | Only if different |
| What happened? | |
| Result | Known / Reported / Unknown / Corrected, plus a sentence |
| Trace ID | TRK-YYYY-MMDD-HHMM |
| External ID | Only if it exists, and only if it is yours |

- **Trace ID** is the event's own identity on the map, not a platform ID.
- **External ID** is kept in a separate field. If the platform changes, the trace stays.
- **One event, cumulative history.** A new report on the same event joins it.

### 🔬 Four States of Knowledge

| State | Meaning |
|---|---|
| **Known** | Checked against the source or the field |
| **Reported** | Said, not yet checked |
| **Unknown** | Not enough evidence. A valid state, not a failure |
| **Corrected** | Changed after checking |

Don't write "verified". Choose one of the four.

### 📍 The Rules

Every rule here was born from a real mistake caught in the field.

1. **Appears in window X ≠ X wrote it.** Check which zone of the window the text is in: user bubble, reply bubble, compose box, embedded screenshot, process line, placeholder text.
2. **Two voices repeating ≠ two verifications.** Verification needs the source.
3. **Opening the source ≠ reading all of it.**
4. **Source ≠ the reader of the source.** The source has a limit, the reader adds another. What we know is the intersection.
5. **Metadata says what it knows. The screen says what it sees.** Don't swap them.
6. **Evidence must come before the measurement it explains.**
7. **A time written inside the text ≠ the time the screenshot was taken.**
8. **Similar wording ≠ an exact quote.**
9. **A signature answers who, not why.** Don't fill in the gap yourself.
10. **Before blaming, check what was in front of the writer when they wrote.**
11. **Access is not permission.**
12. **Verification comes from the field. Recognition comes from the encounter.**
13. **Don't delete the path.** The error stays, marked "corrected".
14. **Fixing an output ≠ fixing the template that produces it.**
15. **Before making a new map, check the one that already exists.**

### 🌱 The Model

The field happens.
The source keeps.
The observer samples.
The editor chooses resolution.
The map holds traces.

The method's DNA is not hidden inside it. It is the pattern it leaves passing through time, including how it corrects itself.
